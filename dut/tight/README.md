# Tight coupling

Die geplante Erweiterung zu einer allgemeinen NVDLA-Job-ISA steht in
[`ISA_PLAN.md`](ISA_PLAN.md). Sie trennt tatsächlich vorhandene `nv_small`-
Funktionen von optionalen NVDLA-Builds und einem erst noch zu entwickelnden
OS-/WS-Datenpfad.

`relu.c` contains two task-level Custom-0 instructions. `relu8 rd, rs1, rs2`
(`funct3=0`) takes 32-bit, 8-byte-aligned input and output AXI addresses,
configures a fixed 1x1x8 INT8 SDP ReLU job and launches it. It returns 0 on
launch or 1 for invalid addresses. `wait rd` (`funct3=1`) polls SDP
`D_OP_ENABLE` until the job finishes; it returns 0 or 2 on timeout.

`cva6_axi_top.sv` instantiates `ariane_nvdla.sv`, whose CV-X-IF issue,
commit, and result channels connect to `cvxif_sdp.sv`. The instruction unit
accepts a job, waits for commit before changing CSB state, sequences NVDLA
register writes internally, and returns the launch or completion status.
Software no longer handles individual CSB registers.

`system_top.sv` keeps instruction/data traffic and NVDLA DMA traffic on an
AXI crossbar with one shared RAM target. CSB is not an AXI target here.
`test_tight.py` loads firmware and input into an external AXI RAM model,
checks both instruction statuses and all eight ReLU output bytes after DMA
writeback. `build.mk` and `sim.mk` select this
variant's RTL and Cocotb test. Run `make tb-tight` from the repository root.

`conv.c` uses a third Custom-0 instruction (`funct3=2`) to launch a fixed
13×15×64 by 5×3×64×16 INT8 convolution. `cvxif_sdp.sv` sequences the
trace-derived registers, waits for CBUF flush, and enables the full NVDLA
pipeline; the existing `wait` instruction completes the task. The register
table is local to this DUT in `conv_commands.svh`, generated by
`tools/gen_conv.py`. `test_conv.py` verifies the upstream CRC32. Run
`make tb-conv-tight` from the repository root.

The fixed instructions are deliberately narrow. Supporting other tensor shapes
or CPU-produced cached input requires a job descriptor and cache-coherence
handling before it can serve as a general NVDLA instruction interface.
